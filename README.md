# 🪓 Hangman Game in C

**My First Smol Coding Project Done Back in the day :3**  
(Uploaded just to preserve this).

A classic terminal-based Hangman game written in C.  
Guess the word letter by letter before the hangman is complete!

---

## 🎮 Features

- Clear and simple terminal interface  
- ASCII-art Hangman drawing  
- Loads words from a file (`words.txt`)  
- Tracks incorrect guesses (up to 6)
